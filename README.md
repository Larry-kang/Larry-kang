## 我如何做這些專案

從自己遇到的問題出發，先討論需求、規格與驗收方式，再與 AI Agent 協作實作，持續使用並調整成果。

GAS Asset Tracker 與原始 PetPet 的初版由我手寫；目前上述專案的後續開發大量使用 AI，實作主要由 Agent 完成，我負責需求決策、規格討論與結果驗收。各專案的細節與進度請見 README。
